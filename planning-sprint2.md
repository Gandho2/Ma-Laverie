# Planning — Suite du projet Ma Laverie

## Objectif général

Le prochain sprint a pour objectif d’améliorer les fonctionnalités du MVP et de rendre l’application plus complète.


# Semaine 1

## Objectifs

- Mise en place du système de connexion
- Création des utilisateurs
- Début intégration base de données MySQL

## Tâches

- Création formulaire connexion
- Création formulaire inscription
- Création routes API utilisateurs
- Tests de connexion


# Semaine 2

## Objectifs

- Gestion des réservations utilisateur
- Historique des réservations

## Tâches

- Sauvegarde des réservations
- Affichage historique
- Liaison utilisateurs/réservations


# Semaine 3

## Objectifs

- Amélioration interface utilisateur
- Responsive mobile

## Tâches

- Modernisation du design
- Organisation des pages
- Amélioration expérience utilisateur


# Résultat attendu

À la fin du sprint 2, l’application devra proposer une expérience plus complète avec une gestion réelle des utilisateurs et des réservations.
