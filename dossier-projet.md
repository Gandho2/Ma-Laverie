# Dossier Projet — Ma Laverie

## Présentation du projet

Le projet Ma Laverie a été réalisé dans le cadre de la formation Concepteur Développeur d’Applications à l’École IT.

L’objectif du projet est de concevoir une application web permettant aux utilisateurs de consulter les disponibilités des machines dans des laveries et d’effectuer des réservations en ligne.

Ce projet répond à un problème fréquent : les utilisateurs ne savent pas toujours si des machines sont disponibles avant de se déplacer dans une laverie.

L’application a donc pour but de proposer une solution simple et accessible permettant :
- de consulter les machines disponibles
- de réserver une machine
- de réduire le temps d’attente
- d’améliorer l’expérience utilisateur

Le projet est actuellement développé sous forme de MVP (Minimum Viable Product) afin de mettre en place les fonctionnalités principales avant d’ajouter des fonctionnalités plus avancées.


# Organisation du projet

Le projet est organisé selon une méthode Agile avec plusieurs sprints.

Chaque sprint permet :
- de définir des objectifs
- de développer progressivement les fonctionnalités
- de réaliser des tests
- d’améliorer le projet en fonction des retours obtenus

Le suivi du projet est réalisé avec GitHub Projects afin d’organiser les tâches, suivre l’avancement et gérer les priorités.

Les différents rendus ont permis d’améliorer progressivement le projet grâce aux remarques obtenues durant le développement.

# Fonctionnalités développées

Plusieurs fonctionnalités ont été développées durant le projet.

## Backend

- Création d’un serveur Express
- Création des routes API
- Consultation des machines
- Réservation d’une machine
- Gestion simple des erreurs

## Frontend

- Création d’une interface HTML
- Formulaire de réservation
- Communication avec le backend via JavaScript
- Affichage des messages de confirmation

## Tests

- Mise en place de Jest
- Réalisation de tests unitaires
- Vérification du bon fonctionnement des réservations


# Évolution du projet

Le premier sprint a permis de mettre en place les bases du projet :
- conception
- architecture
- maquettes
- diagrammes UML
- MCD / MLD / MPD

Le second sprint a permis de développer une première fonctionnalité complète avec :
- frontend
- backend
- API REST
- réservation
- tests unitaires

Le projet continuera ensuite avec :
- intégration d’une base de données MySQL
- authentification utilisateur
- amélioration de l’interface
- gestion des réservations avancées


# Conclusion

Le projet Ma Laverie a permis de mettre en pratique plusieurs compétences importantes :
- développement frontend
- développement backend
- conception logicielle
- tests
- organisation Agile
- utilisation de GitHub

Cette première version constitue une base fonctionnelle qui pourra être améliorée progressivement dans les prochains sprints.
